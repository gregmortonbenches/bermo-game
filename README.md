# GTA Bermondsey

A wholesome GTA III-style 3D game set in real Bermondsey, south-east London, built with three.js.
Borrow cars (politely), fly the police helicopter, help the neighbours and save up for a coffee cart.

**Play:** https://gregmortonbenches.github.io/bermo-game/

Controls: WASD or arrows to move, drag the mouse to look, E to interact, Shift to run, Space to jump or brake, Q to climb in the helicopter, M for the map, B for your bag. On phones: left stick to move, right stick to look, A to interact.

Notes
- Static site: no build step. three.js loads from jsdelivr.
- Progress saves in your browser. The online crew link-up only works in the claude.ai version.
